FormFlow 01 / Problem

Problem

What I am solving

Develop a computer-vision-based system that captures freehand sketches through hand gestures and combines multiple 2D views (Front, Top, and Side) to reconstruct an approximate 3D representation without conventional CAD modelling.

Turning an idea into 3D usually needs CAD skills and conventional input devices. That friction slows rapid experimentation for beginners and non-experts.

FormFlow 02 / Solution

Solution

Hands as a virtual pencil. Webcam as the canvas. Geometry as the engine. No custom AI/ML training.

MODE 01

Rapid 3D Prototyping

Draw directly in 3D space. Index fingertip trajectory becomes a spatial sketch I can rotate, inspect, and export.

MODE 02 / PRIMARY

Multi-View 2D to 3D

Draw Front, Top, and Side views. Extract contours, align dimensions, then build a 3D volume with Visual Hull.

FormFlow 04 / Workflow

Workflow

End-to-end path from gesture to 3D model

01
Capture

Webcam detects the hand. Index fingertip acts as a virtual pencil. Pinch toggles drawing on/off.

02
Draw

Mode 1: sketch freely in 3D. Mode 2: draw Front, Top, and Side orthographic views of the same object.

03
Process

Smooth strokes, threshold, morphology, extract contours, align shared dimensions across views.

04
Reconstruct (Visual Hull)

Back-project Front, Top, and Side silhouettes, intersect the volumes (Visual Hull), generate mesh, view and optionally re-edit.

05
Export

Save the approximate prototype as OBJ, STL, or OpenSCAD (.scad).
